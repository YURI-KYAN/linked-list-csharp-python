# Lista Ligada (Linked List) - C# e Python

Projeto de Estrutura de Dados desenvolvido durante formação em Ciência da Computação.

### 🔧 Funcionalidades
- Inserção no início e fim
- Remoção por valor
- Busca e exibição
- Tratamento de lista vazia e nó único

### 📚 Conceitos Aplicados
- TAD (Tipo Abstrato de Dados)
- Alocação dinâmica de memória
- Complexidade: O(1) inserção no início | O(n) busca/remoção

### 💻 Tecnologias
`C#` `Python` `Algoritmos`

### ▶️ Como executar
```bash
# Python
python lista.py

# C#
dotnet run
